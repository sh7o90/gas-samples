# 03 申込フォーム（定員・締切つき）

Google フォームの申込を自動で**申込一覧**にまとめ、**受付番号つきの確認メール**を返します。**定員に達した日程・締切を過ぎた日程は、フォームの選択肢から自動で外れます**。

## こんな仕事の方に
- 料理教室・ヨガ・セミナーなど、日程ごとに定員がある申込
- 説明会・見学会・送迎など、締切のある予約
- イベントの参加受付

フォームとスプレッドシートだけで動くので、**予約システムの月額料金がかかりません**。

## できること
| 動き | 内容 |
|---|---|
| 申込が届いたとき（自動） | 受付番号（A-0001…）を振って申込一覧へ → 申込者に確認メール → 管理者に通知 |
| 定員に達したとき（自動） | その日程をフォームの選択肢から外す（受付中の日程がなくなったらフォームを閉じる） |
| 締切を過ぎたとき（自動・毎日 0:05） | その日程をフォームの選択肢から外す |
| 同時に申込が来たとき | 届いた順に1件ずつ判定するので、**定員を超えて受け付けません** |
| 席が足りないとき | 満席の日程は選択肢に出ません。残りの席より多い人数で申し込まれたときは、お断りのメールを送ります |

## 使い方（見本を試す）
1. 「ファイル」→「コピーを作成」で自分のドライブにコピー
2. メニュー「申込フォーム」→「見本を作る（フォームと見本データ）」（初回は権限の確認が出ます）
3. 表示された**回答用 URL** を開いて申し込む
4. 見本では、すべてのメールが「設定」タブの **テスト送信先** に届きます（件名に本来の宛先が `[テスト→…]` と付きます）

## タブ
| タブ | 中身 |
|---|---|
| 開催日程 | 日程 ／ 開催日時 ／ 定員 ／ 申込数（自動）／ 残り（自動）／ 締切 |
| 申込一覧 | 受付番号 ／ 受付日時 ／ お名前 ／ メール ／ ご希望の日程 ／ 人数 ／ 状態（受付・取消） |
| フォームの回答 1 | フォームが自動で書き込む（触らない） |
| 設定 | 主催者 ／ 連絡先 ／ 管理者メール ／ テスト送信先 ／ メールの文面 ／ 満席のときの文 ／ 締切のときの文。**「説明」列に、各項目の意味と、文面で使える `{ }` が書いてあります** |
| ログ | いつ・何を・成功/失敗 |

- 取消は、申込一覧の「状態」を「取消」に変えて、メニューの「申込数と選択肢を今すぐ更新」を押すと、席が空いてフォームに戻ります

## 本番で使うときの注意
- 「テスト送信先」を**空にする**と、本来の宛先に送ります
- 無料の Google アカウントは、1日に送れるメールの数に上限があります
- 決済（事前の支払い）、LINE での受付などはご相談ください
